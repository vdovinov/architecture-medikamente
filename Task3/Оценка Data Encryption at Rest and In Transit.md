# Оценка Data Encryption at Rest and In Transit #

| Данные                                                                                      | В чём необходимость защиты                                                                                                 | Инструменты защиты                                                                                                                                                    |
|---------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Специальные категории ПДн** (диагнозы, история болезней, результаты анализов, назначения) | Нарушение 152-ФЗ, репутационные потери                                                                                     | В покое: PostgreSQL с pgcrypto/TDE + HashiCorp Vault (управление ключами); MinIO SSE‑KMS для файлов. При передаче: Istio mTLS (внутри), Kong/NGINX TLS 1.3 (внешние). |
| **Общие персональные данные** (ФИО, дата рождения, телефон, email, адрес, полис, СНИЛС)     | Обязательная защита согласно 152-ФЗ, риск утечки                                                                           | В покое: PostgreSQL pgcrypto + Vault; MinIO SSE‑KMS. При передаче: mTLS, TLS 1.3.                                                                                     |
| **Платёжные данные** (суммы, номера чеков, способы оплаты, проводки)                        | Требования Платежной системы, финансовые потери при утечке                                                                 | В покое: PostgreSQL с шифрованием финансовых полей; MinIO для чеков (SSE‑KMS). При передаче: TLS 1.3, интеграция с 1С через REST API (HTTPS).                         |
| **Данные о сотрудниках** (зарплата, паспортные данные, СНИЛС, ИНН)                          | Нарушение трудового и налогового законодательства; утечка банковских реквизитов                                            | В покое: PostgreSQL шифрование (pgcrypto) с доступом только у HR и бухгалтерии. При передаче: mTLS.                                                                   |
| **Обезличенные аналитические данные** (агрегаты, статистика, датасеты для ML)               | Не содержат прямых идентификаторов, но могут быть подвергнуты реидентификации при комбинации; требуют контроля целостности | В покое: ClickHouse с шифрованием. При передаче: TLS.                                                                                                                                                                       |
