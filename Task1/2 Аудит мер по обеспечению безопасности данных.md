## Сопоставление процессов в компании с требованиями по обеспечению безопасности данных ##

| Требование                        | Текущее состояние                                                                       |
|-----------------------------------|-----------------------------------------------------------------------------------------|
| Разграничение доступа (RBAC/ABAC) | Отсутствует: доступ к папкам через AD, но без учёта ролей (врач/кассир/админ).          |
| Шифрование данных при хранении    | Нет: данные в Excel, PDF, JPG лежат в открытом виде на файловом сервере.                |
| Шифрование при передаче           | TLS не используется для 1С (OLE), Exchange может использовать TLS, но не гарантировано. |
| Аудит доступа к данным            | Отсутствует: нет логов кто, когда и какие файлы открывал.                               |
| Управление инцидентами            | Нет системы алертинга при нештатном доступе.                                            |
| Сроки хранения и удаление         | Нет политики: данные хранятся бессрочно.                                                |
| Privacy by Design                 | Не применяется: системы проектировались без учёта защиты данных.                        |
| Data Minimization                 | Собираются все возможные данные, даже не нужные для оказания услуги.                    |



## Список проблемных зон: ##
1) **Отсутствие классификации данных** – нет понимания, где и какие ПДн хранятся.
2) **Неконтролируемый доступ** – файловая шара открыта всем сотрудникам.
3) **Нет шифрования** – данные в покое и при передаче не защищены.
4) **Нет аудита** – невозможно отследить факт утечки.
5) **Дублирование данных** – Excel дублирует 1С, что увеличивает поверхность атаки.
6) **Небезопасные интеграции** – OLE, файловый обмен, почта.
7) **Отсутствие политик жизненного цикла данных** – нет автоматического удаления.
8) **Нет контроля за аналитикой** – бизнес-аналитик выгружает данные на локальный ПК.
9) **Нет систем мониторинга и алертинга** – инциденты не фиксируются.
